# Neovim Configuration

A streamlined, modern Neovim IDE configuration tailored for development, featuring syntax parsing, language servers, auto-completion, and local AI integration.

> **Note:** The entirety of this configuration code was 100% generated by AI. 

---

## 🛠️ Tech Stack & Plugins

* **Package Manager:** [lazy.nvim](https://github.com/folke/lazy.nvim)
* **Theme:** [Catppuccin](https://github.com/catppuccin/nvim) (Macchiato flavor)
* **Syntax Highlighting:** [Treesitter](https://github.com/nvim-treesitter/nvim-treesitter) (C, Python, Bash)
* **LSP & Management:** [Mason.nvim](https://github.com/williamboman/mason.nvim) (`clangd`, `basedpyright`, `bashls`)
* **Completion:** [nvim-cmp](https://github.com/hrsh7th/nvim-cmp)
* **Local AI Assistant:** [CodeCompanion.nvim](https://github.com/olimorris/codecompanion.nvim) powered by [Ollama](https://ollama.com/)

---

## ⚙️ Customization

If you clone or fork this configuration, you can easily tweak it to fit your workflow directly inside `init.lua`:

1. **Theme Flavor:** Change `"macchiato"` under the Catppuccin setup to `"latte"`, `"frappe"`, or `"mocha"`.
2. **Languages & LSPs:** Add new language parsers to `ensure_installed` under Treesitter and enable their respective LSPs under `nvim-lspconfig`.
